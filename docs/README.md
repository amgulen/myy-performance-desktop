# 蒙医云绩效管理桌面系统 - 项目上下文

---

## 项目概述

蒙医云医院绩效管理桌面系统，用于管理医院多套绩效制度的计算、配置、查询和导出。

---

## 当前阶段

**需求提炼与规格固化阶段（Phase 0-1）**

当前不进入设计阶段和开发阶段。

---

所有绩效制度原始文件存放于 `source/` 目录：

- `source/蒙医云医院检验科项目计件绩效制度（2025 版）(1).docx`

## 数据来源说明

**重要提醒（本阶段已明确）：**

- 医院当前无HIS系统
- 明确数据来源：**ABC数字医疗云开放平台**（接口文档入口：https://open-region2.abcyun.cn/）
- 该文档页面可能包含多个子页面/多个接口模块，后续设计阶段需要逐页学习整理
- 数据获取方式：ABC接口（待分析）+ Excel导入 + 手工录入
- **不得**假设HIS/LIS/收费系统已存在

**ABC接口相关本地配置项（仅作配置项，不写死）：**
- ABC接口地址配置
- AppId配置
- AppSecret本地加密保存
- 接口连接测试
- 接口数据同步日志
- 接口失败重试与错误提示
