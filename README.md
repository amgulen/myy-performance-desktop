## 支持的绩效模型（6类）

1. **比例计提模型** — 按项目分类金额乘以计提比例（挂号费、一人一方、检验检查类）
2. **固定金额模型** — 按人次/次数/份数发放固定金额（夜班费、住院病历费）
3. **计件模型** — 数量×单价×岗位系数（检验科各类项目计件）
4. **阈值后计提模型** — 达到基准线后仅对超出部分计提（非药物特色治疗超额部分）
5. **评分考核模型** — 多指标加权评分×等级系数（出诊专家综合考核）
6. **扣罚/质量控制模型** — 投诉、报告错误等扣减绩效（报告错误、质控不合格）

> 制度文件中的比例、金额、权重均为"示例参考"，不得作为代码写死的规则。
