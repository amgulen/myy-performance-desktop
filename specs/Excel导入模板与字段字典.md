# Excel导入模板与字段字典

**版本：** V1.0
**日期：** 2026-05-25
**状态：** 可实施设计稿
**定位：** 开发验证通路、ABC 异常兜底、历史补录与业务修正

---

## 1. 设计原则

Excel 数据与 ABC 数据享有相同的归一化和追溯要求。Excel 不直接承载计算公式，不直接生成最终绩效金额。

模板设计采用“稳定基础模板 + 可选业务补充模板”：

- 基础原子数据所需字段保持稳定，不能因调整某个比例而反复变化。
- 新增业务维度时，可以增加补充模板或扩展字段定义。
- 每次导入形成批次，原文件、校验结果、修正记录和映射版本可追溯。
- 制度值进入规则配置模板，不进入业务数据导入表。

---

## 2. 模板集合

| 模板 | 用途 | 是否必须支持 |
|---|---|---:|
| `业务明细导入模板` | 收费、处方、检验、治疗、病历、夜班等可计量事件 | 是 |
| `冲减记录导入模板` | 退费、作废、退药、撤销记录 | 是 |
| `人员与科室映射模板` | ABC 不完整或历史补录场景下维护人员主数据 | 是 |
| `项目分类映射模板` | 外部项目归类到绩效项目分类 | 是 |
| `质量扣罚事件模板` | 投诉、质控、延迟、违规等事件录入 | 是 |
| `评分指标录入模板` | 满意度、质量评分等非自动来源指标 | 是 |
| `成本扣减模板` | 需要按净收入扣除耗材成本的项目/期间数据 | 可选启用 |
| `科室二次分配模板` | 启用二次分配规则时录入分配依据 | 可选启用 |

---

## 3. 通用导入规则

| 规则 | 说明 |
|---|---|
| 文件格式 | `.xlsx`，首行为字段名，模板包含说明页和数据页 |
| 批次标识 | 每次导入自动生成，记录文件名、导入时间、模板版本和校验结果 |
| 行状态 | 成功、失败、待映射、重复、疑似冲突、已修正 |
| 错误处理 | 错误行不阻断其余合法行导入，必须可导出错误反馈 |
| 重复判断 | 以来源类型、业务单号、行号、事件类型、发生时间等形成幂等判断 |
| 修正方式 | 修正记录新增版本，不覆盖已保留的来源记录 |
| 模板版本 | 模板字段变动必须升级版本，旧批次继续关联旧模板 |

## 4. 业务明细导入模板

### 4.1 字段字典

| 字段名 | 类型 | 必填 | 示例 | 说明 |
|---|---|---:|---|---|
| `业务单号` | 文本 | 是 | `CHG-202605-001` | 来源系统或人工定义的稳定单号 |
| `业务明细行号` | 文本 | 否 | `1` | 同单多项目时建议填写 |
| `事件类型` | 枚举 | 是 | `收费` | 收费、处方、检验、治疗、病历、护理、夜班、其他 |
| `发生时间` | 日期时间 | 是 | `2026-05-01 09:20` | 用于规则版本和计算周期匹配 |
| `人员工号` | 文本 | 条件必填 | `D001` | 与人员姓名至少一个可解析 |
| `人员姓名` | 文本 | 条件必填 | `示例医生` | 仅用于匹配和展示，不作为唯一主键优先项 |
| `科室编码` | 文本 | 否 | `MZ001` | 未填写时可依据人员映射补全并记录来源 |
| `科室名称` | 文本 | 否 | `门诊部` | 显示及辅助匹配 |
| `岗位编码` | 文本 | 否 | `YS` | 供岗位系数规则匹配 |
| `项目编码` | 文本 | 条件必填 | `LAB-CBC` | 与项目名称至少一个可映射 |
| `项目名称` | 文本 | 条件必填 | `血常规` | 项目分类映射依据 |
| `项目分类编码` | 文本 | 否 | `LAB` | 可由映射规则生成 |
| `数量` | 数值 | 是 | `3` | 允许小数，必须大于或等于零 |
| `单位` | 文本 | 是 | `次` | 次、份、人日、项等 |
| `金额` | 金额 | 条件必填 | `120.00` | 金额型规则需要；计件事件可为空 |
| `数据备注` | 文本 | 否 | `历史补录` | 不参与规则计算 |

### 4.2 校验要求

- 业务单号、事件类型和发生时间必须存在。
- 人员、项目必须可映射，否则进入待映射清单。
- 数量不能为负；冲减必须使用冲减模板表达。
- 金额型项目缺失金额时不得进入金额规则计算。
- 同一幂等键重复导入时标记重复，不再次生成原子数据。

## 5. 冲减记录导入模板

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---:|---|
| `冲减单号` | 文本 | 是 | 退款、退药或作废的业务单号 |
| `原业务单号` | 文本 | 是 | 关联原正向记录 |
| `原业务明细行号` | 文本 | 否 | 对应项目行 |
| `冲减类型` | 枚举 | 是 | 退费、退药、作废、撤销 |
| `冲减发生时间` | 日期时间 | 是 | 冲减所属时间 |
| `项目编码` | 文本 | 否 | 明细冲减时填写 |
| `冲减数量` | 数值 | 否 | 数量冲减口径 |
| `冲减金额` | 金额 | 否 | 金额冲减口径 |
| `冲减原因` | 文本 | 是 | 追溯展示所需 |

校验要求：

- `冲减数量` 与 `冲减金额` 至少填写一个。
- 无法找到原业务记录时，保存为待关联记录，不直接进入正式计算。
- 锁定周期新增冲减记录时，提示生成复算批次，不覆盖历史结果。

## 7. 补充业务模板

### 7.1 质量扣罚事件模板

| 字段名 | 必填 | 说明 |
|---|---:|---|
| `事件单号` | 是 | 唯一标识 |
| `人员工号` | 是 | 责任归属人员 |
| `发生时间` | 是 | 所属计算周期 |
| `事件类型` | 是 | 与扣罚规则匹配 |
| `关联业务单号` | 否 | 可关联具体绩效明细 |
| `严重程度` | 否 | 规则匹配参数 |
| `事实说明` | 是 | 追溯依据 |

模板不录入最终扣款金额，金额或扣分由已启用扣罚规则计算。

### 7.2 评分指标录入模板

| 字段名 | 必填 | 说明 |
|---|---:|---|
| `指标记录号` | 是 | 唯一标识 |
| `人员工号` | 是 | 评分对象 |
| `考核周期` | 是 | 月度、季度或自定义周期 |
| `指标编码` | 是 | 与评分规则指标关联 |
| `指标值` | 是 | 原始值或经确认得分 |
| `数据来源说明` | 是 | 手工、调查、质控等 |
| `备注` | 否 | 评分依据 |

## 8. 模板与规则配置关系

| 信息类型 | 存放位置 |
|---|---|
| 业务实际发生数量、金额、时间、单号 | Excel 业务数据模板 |
| 退费、作废、退药事实 | Excel 冲减模板 |
| 比例、单价、金额标准、阈值、系数、权重 | 规则配置，不写入业务明细模板 |
| 规则版本、生效时间 | 规则配置 |
| 人工调整金额与原因 | 结果调整流程，不混入原始数据模板 |

---

## 9. 开发验收要求

1. 模板可生成并包含字段说明与模板版本。
2. 合法业务数据能转换为绩效原子数据，并保留导入批次。
3. 错误行、待映射行和重复行可分别反馈。
4. 冲减记录能关联原业务并展示净额处理路径。
5. 修改规则数值不要求修改基础业务模板字段。
6. Excel 导入与 ABC 同步产生的原子数据可进入同一计算流水线。
