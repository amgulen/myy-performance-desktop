# 蒙医云绩效管理桌面系统 - 需求规格文档 V1.0

---

## 1. 项目背景

蒙医云医院已建立多套绩效制度体系，涵盖：
- 出诊专家项目计提
- 专家绩效评分考核（多维度加权）
- 检验科计件绩效
- 非药物特色治疗绩效（项目积分制）
- 住院医师绩效
- 护理绩效
- 夜班补贴

**当前痛点：**
- 数据分散在多个来源（HIS/LIS/收费系统/人工统计）
- 多模型叠加导致计算复杂
- 手工计算成本高、错误率高
- 规则调整需改代码，无法快速响应制度变更
- 计算结果无法完整追溯
- 无统一系统支撑绩效管理全流程

---

## 2. 项目目标

构建一套：
- **本地运行**：Windows桌面应用，数据不出本地
- **解压即用**：无需安装环境，解压即可运行
- **无需部署**：不依赖服务器或云服务
- **高度可配置**：所有绩效规则、比例、阈值均可配置
- **支持多绩效模型**：比例计提、计件、积分制、评分考核、固定补贴

的绩效管理系统。

---

## 3. 软件形态

- **Windows桌面应用程序**（Electron + React + TypeScript）
- **SQLite本地数据库**
- **解压即用绿色软件**，无安装依赖
- **单文件或压缩包发布**，GitHub Release分发
- **不依赖任何外部服务**（不含MySQL/Redis/云数据库/服务器）

## 7. 当前绩效制度提炼

### 模型一：计件模型（检验科）

**规则：**
- 按检验项目数量 × 单件金额计算
- 项目金额表：血常规0.4元/次，尿液检验0.4元/次，粪便常规1.0元/次，生化单项0.2元/项，生化全套5元/次，免疫单项1元/项，C13呼气试验2元/次，外送检2元/次
- 岗位系数：待配置
- 质量扣罚前置：报告单错误扣10%，外部质控不合格扣5%-20%，报告延迟扣1-5元/次，样本重做扣该项目金额100%，投诉属实扣10-50元/次

**公式：**
```
个人计件绩效 = ∑(项目数量 × 项目计件金额) × 岗位系数 - 质量扣罚
```

### 模型二：项目积分制（住院/非药物/出诊专家）

**规则：**
- 项目分为三类：一类1-3分，二类4-6分，三类7-10分
- 积分单价 = 绩效工资总额 ÷ 全院总积分（动态，每季度调整）
- 质量考核系数：优秀1.1，良好1.0，合格0.8，不合格0.5

**公式：**
```
个人月度绩效 = ∑(项目积分 × 积分单价) × 质量考核系数
```

### 模型三：评分考核模型（出诊专家绩效考核）

**规则：**
- 四维度考核：工作量40% + 医疗质量30% + 患者满意度20% + 科研教学10%
- 每维度满分100分，按权重加权
- 考核等级：优秀≥90分系数1.2，良好75-89分系数1.1，合格60-74分系数1.0，基本合格50-59分系数0.8，不合格<50分系数0.5

**公式：**
```
综合考核得分 = 工作量得分×40% + 医疗质量得分×30% + 患者满意度得分×20% + 科研教学得分×10%
岗位绩效工资 = 绩效工资标准 × 考核等级系数
```

### 模型四：固定补贴模型

**规则：**
- 固定金额按次数或人数发放
- 示例：夜班费100元/次，住院病历100元/份

## 8. 必须支持的绩效场景

1. **检验科计件绩效计算**：根据检验项目数量和计件金额表计算个人绩效
2. **非药物特色治疗绩效计算**：根据项目积分和积分单价计算
3. **出诊专家项目计提**：根据专家诊疗项目积分计算
4. **出诊专家绩效考核**：四维度加权评分，等级系数计算
5. **多规则叠加计算**：同一人员可能同时适用多种绩效模型
6. **质量扣罚计算**：根据质量事件扣减绩效
7. **按月/人/科室多维度查询**
8. **绩效结果明细追溯**：查看每笔绩效的计算来源和规则

| 配置项 | 说明 |

| 积分项目分类和分值 | 一类/二类/三类项目及对应分值 |

| 考核等级分数段 | 各等级分数区间和系数 |
| 质量扣罚规则 | 扣罚事件类型和扣罚比例 |
| 岗位系数 | 不同岗位的绩效系数 |
| 固定补贴标准 | 夜班费等固定金额 |
| 规则版本管理 | 支持规则版本和生效时间 |

## 10. 查询与报表需求

- 按年/月/季度查询绩效数据
- 按人员姓名/工号查询
- 按科室查询汇总和明细
- 按项目分类查询
- 明细钻取：可查看每笔绩效的计算过程（用了哪些数据、用了哪条规则、计算路径）
- Excel导出：支持汇总表和明细表导出

---

## 11. 备份恢复需求

- **手动备份**：用户可随时触发完整数据库备份
- **自动备份**：每次启动应用时自动备份（或按配置周期）
- **导入恢复**：支持通过备份文件完整恢复数据
- **换电脑恢复**：备份文件拷贝到新电脑后可直接恢复

## 16. Excel导入/手工录入边界

### Excel导入

- 需定义标准导入模板（含表头和数据格式）
- 支持导入数据校验（数据格式、必填项、值域检查）
- 需支持人员匹配（根据姓名或工号匹配系统内员工）
- 需支持项目分类映射
- 错误数据行需标记并反馈，不阻断整表导入

### 手工录入

- 支持逐条添加数据（适合数据量小的补充录入）
- 支持批量编辑
- 需记录录入时间和录入人
