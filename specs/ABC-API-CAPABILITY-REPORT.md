# ABC接口能力评估报告

**文档版本：** V1.0
**评估日期：** 2026-04-24
**接口文档入口：** https://open-region2.abcyun.cn/

---

## 一、评估方法

通过curl抓取接口文档页面，解析TOC目录结构（共400+数据模型定义，21个接口模块），提取所有接口名称和路径，对照绩效系统需求进行能力映射。

**不调用真实接口，不使用AppSecret，仅做文档分析。**

---

## 三、各数据类型详细评估

### 3.1 人员数据

**接口模块：** 5.1 基础信息接口 + 5.2 医生接口

**已明确支持的接口：**

| 接口名称 | 功能 |
|---|---|
| 获取科室列表 | 按诊所获取科室列表 |
| 获取门店信息 | 门店基础信息 |
| 获取科室详情 | 科室详细信息 |
| 获取人员详情 | 单个人员完整信息（含科室归属） |
| 获取门店人员列表 | 门店下所有人员 |
| 获取门店人员科室列表 | 人员与科室的多对多关系 |
| 根据手机号获取医生信息 | 按手机号查找医生 |
| 获取医生分页列表信息 | 医生分页查询 |

**绩效系统可用字段（预估）：**
- 人员ID、工号、姓名、手机号
- 科室ID、科室名称
- 岗位类型、职称
- 人员类型（医生/护士/技师等）

**评估结论：✅ 已明确支持**
人员基础数据接口完整，可支撑员工管理模块。

## 六、综合评估

### 6.1 绩效系统数据覆盖度

| 绩效模型 | 所需数据 | ABC接口支撑 | 状态 |
|---|---|---|---|
| 比例模型（固定比例） | 收费项目+金额+分类 | 收费明细-分类/明细，处方数据 | ✅ 支持 |
| 比例模型（动态比例/积分制） | 收费总额+项目积分 | 统计接口-执行业绩，收费明细 | ✅ 支持 |
| 计件模型 | 检验项目+数量 | 检查检验接口（按患者/按日期） | ✅ 支持 |
| 阈值后计提模型 | 收入金额+基准线 | 收费明细-分类/单据 | ✅ 支持 |
| 评分考核模型 | 工作量指标 | 挂号+执行+门诊接口 | ✅ 部分支持（需确认字段） |
| 扣罚模型 | 退费记录+作废记录 | 收费退款+发药退药+检验作废 | ✅ 支持 |

### 6.2 关键风险

| 风险 | 等级 | 说明 |
|---|---|---|
| 接口调用频率限制未明确 | 中 | 可能影响大批量数据同步 |
| 数据字段详情未完全确认 | 中 | 需进一步读取接口详细页面确认字段名和格式 |
| 事件订阅（推送）能力待确认 | 中 | 实时同步依赖推送机制，文档仅有"查询推送失败事件" |

### 6.3 设计阶段建议

1. **优先使用统计接口（5.10）**：执行业绩-明细接口可能是绩效系统最直接的数据来源，设计阶段需优先分析该接口字段
2. **备用方案**：若统计接口字段不足，收费明细+检查检验接口可作为数据来源组合
3. **数据同步策略**：优先按月/按日批量拉取，不依赖实时推送
