# 设计决策与可配置化收口清单

**版本：** V1.0
**日期：** 2026-05-25
**状态：** 设计收口基线
**关联需求基线：** `SPEC.md` V1.1（2026-04-26 已冻结）

---

## 1. 文档目的

院方当前能够提供的需求资料以 `source/` 中制度文件及已冻结的 V1.1 需求为限。对制度未明确、后续可能变动的业务口径，不再等待不存在的补充资料才设计系统，而采用以下原则推进：

- 能配置的业务规则全部配置化，并保留版本和生效时间。
- 尚未确认的制度值不作为系统默认启用规则，不写死到程序中。
- 必须由真实外部条件决定的事项，例如 ABC 鉴权字段和账号权限，在实际联调前保持为待绑定项。
- 配置化不能削弱数据来源留痕、计算追溯、结果锁定、敏感信息保护等系统约束。

本文属于设计决策记录，不直接修改已冻结的需求范围。若后续新增或删除 V1 功能，仍应走需求变更流程。

## 2. 已确定设计决策

| 编号 | 事项 | 设计决策 | 对开发的影响 |
|---|---|---|---|
| D-01 | 未确定的业务数值 | 比例、金额、权重、阈值、系数、评分档位、扣罚标准均作为规则参数配置 | 代码中不得出现制度数值常量 |
| D-02 | 默认模板 | 制度文件可转为“参考模板”，首次导入后为草稿，管理员确认启用并生成规则版本 | 参考值不能自动参与正式计算 |
| D-03 | 科室二次分配 | 设计为可选规则阶段，V1 默认关闭；开启后同样形成追溯记录 | 不阻塞个人绩效主流程 |
| D-04 | 动态积分周期 | 周期类型配置化，支持月度、季度或自定义周期；默认使用计算批次指定周期 | 不假设固定为季度 |
| D-05 | 岗位系数 | 按岗位/人员范围配置并版本化；未配置时不得隐式采用任意系数 | 未命中应进入待处理清单 |
| D-06 | 夜班及固定补贴金额 | 固定金额规则配置化，参考模板可录入制度示例但默认草稿状态 | 后续制度变化无需改代码 |
| D-07 | 质量扣罚审批 | V1 不引入审批流；支持扣罚事件录入、依据附件说明、规则执行、人工调整和锁定 | 未来审批属于扩展功能 |
| D-08 | 历史数据补录 | 通过 Excel/手工来源按配置的期间导入，不预设必须导入年份 | 数据源模型必须支持历史批次 |
| D-09 | 人员信息来源 | ABC 为主来源，Excel/手工允许补充和修正，保留来源与映射记录 | 避免联调前阻塞组织模型开发 |
| D-10 | 规则变更留痕 | 规则版本、变更原因、生效时间为业务追溯必需能力，不等同于多用户审计系统 | V1 必须实现业务留痕 |
| D-11 | 净收入口径 | 退费、作废、退药必须先冲减形成有效净收费；规则可继续选择是否扣除耗材等成本，成本数据可导入或手工补充 | 不允许配置绕过冲减，不在执行器内固化成本项 |
| D-12 | 结果复算 | 锁定周期不得覆盖修改；出现补录或冲减时创建新计算批次并比较差异 | 确保历史结果可解释 |

## 3. 不因配置化而放宽的硬约束

以下事项不是“用户可随意配置”的业务参数，而是 V1 实现必须守住的系统约束：

| 约束 | 说明 |
|---|---|
| 统一输入 | ABC、Excel、手工数据必须先转换为绩效原子数据 |
| 原始数据不覆盖 | 修正、冲减和人工调整均须保留原数据及关联原因 |
| 规则版本固定 | 每次计算结果必须引用命中的具体规则版本快照 |
| 计算路径可追溯 | 输入、规则命中、每阶段中间值、调整和最终值均可查看 |
| 凭据保护 | AppSecret 等外部凭据不得明文显示或写入导出报表/日志 |
| 锁定保护 | 锁定结果不能被导入、重算或规则编辑直接覆盖 |
| `core` 独立 | 规则、计算、映射和追溯逻辑不得依赖 Electron 或 React |

## 4. 未决事项的处理方式

### 4.1 不阻塞核心开发的事项

这些事项已经转换为配置项，可在开发测试阶段使用草稿模板和验收样例验证：

- 具体计提比例、单价、固定补贴金额。
- 岗位系数与人员类型差异。
- 阈值额度和阶梯配置。
- 评分维度、权重、档位和等级系数。
- 扣罚金额、比例或扣分方式。
- 积分制结算周期。
- 是否开启科室二次分配。
- 需要补录的历史期间。

### 4.2 不阻塞模型设计、但阻塞真实接入验收的事项

| 事项 | 开发阶段策略 | 正式验收前必须完成 |
|---|---|---|
| ABC AppId/AppSecret | 提供安全配置入口和模拟适配器设计 | 获取医院可用凭据并完成连接测试 |
| ABC 真实字段 | 以逻辑字段映射契约开发适配边界 | 用实际响应样例绑定字段并验证 |
| 接口调用限制 | 同步策略支持可配置分页、窗口和重试 | 确认平台限制并完成压力/失败验证 |
| 数据完整性 | Excel 验收数据先验证计算流水线 | ABC 同步与报表口径完成对账 |

## 5. 配置生命周期

规则与映射配置统一采用以下生命周期：

1. 新建或从参考模板复制为草稿。
2. 填写参数、适用范围、生效时间和变更原因。
3. 使用样例数据试算，不进入正式锁定结果。
4. 启用配置，形成不可变版本快照。
5. 计算批次引用启用版本。
6. 调整规则时创建新版本，不回写历史版本。
7. 停用或归档旧版本，历史结果仍可读取。
